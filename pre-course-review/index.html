Build a strong starting point

Genetics builds on ideas from introductory biology and on basic math skills. Each new topic also builds on material from earlier in the course, so recalling these foundations can make it easier to keep up as the semester progresses.

Use this practice to recall the main ideas, work a few problems, and notice any topics you may want to revisit. We will review several of these ideas in BIO 340.
